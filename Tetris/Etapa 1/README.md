# Tetris Stage 1 experiment

This directory is the durable workspace for the five independent Stage 1 runs.

- `shared/seed.md` is the immutable English prompt used to start each tool.
- `shared/protocol.md` defines the common environment, acceptance criteria and measurement rules.
- `PROGRESS.md` records completed work, commands, outcomes and the next action for hourly continuation.
- Each tool directory contains its own generated specifications, code, transcripts, tests and evidence.
- `report/` contains the final comparison and real metric screenshots.

No Git commits are authorized for this experiment.
