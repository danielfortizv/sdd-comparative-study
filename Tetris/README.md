# Caso de estudio: Tetris

**Responsable:** Kevin Alvarez.

El caso está organizado por etapa y, dentro de cada una, por herramienta. Las cinco variantes son independientes; cada etapa 2 parte exclusivamente de la etapa 1 de su propia herramienta.

```text
Tetris/
├── Etapa 1/
│   ├── OpenSpec/
│   ├── Spec Kit/
│   ├── Tessl/
│   ├── Bmad Method/
│   ├── Kiro/
│   └── shared/
└── Etapa 2/
    ├── OpenSpec/
    ├── Spec Kit/
    ├── Tessl/
    ├── Bmad Method/
    ├── Kiro/
    └── shared/
        ├── acceptance/
        └── report/
```

- [Etapa 1: inicialización](Etapa%201/README.md): juego básico, especificaciones y evidencia de cada herramienta. Su snapshot histórico se conserva.
- [Etapa 2: complejización](Etapa%202/README.md): puntuación, niveles, velocidad, Next y Hold, con métricas, aceptación y SonarQube.
- [Guion breve para presentar la etapa 2 al asesor](Etapa%202/shared/report/guion-tetris-etapa2-asesor.md).

Las etapas posteriores se incorporarán cuando se ejecuten y se verifiquen; no se presentan carpetas vacías como resultados.
