# Common external acceptance catalog — Tetris Stage 2 option A

Researcher-authored checks. Run unchanged against every tool's Stage 2 output. Record `pass`, `fail`, `blocked`, or `not run` for each case and attach raw test output. Unit tests generated by each tool are separate evidence. Use controlled game states or injected piece sequences where needed; document the fixture mechanism without changing generated application code.

| --- | --- | --- |
