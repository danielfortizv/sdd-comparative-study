### API del módulo

| Símbolo | Firma | Descripción |
|---------|-------|-------------|
| `load_keys()` | `() -> tuple[dict[str, bytes], str]` | Parsea `SHIFT_ENC_KEYS` a `{kid: key_bytes}` y resuelve el kid activo (`SHIFT_ENC_ACTIVE_KID`). Valida base64 y longitud de 32 bytes (AES-256). Sin caché: lee el entorno en cada llamada (las pruebas que cambian env no requieren reset). Lanza `CryptoConfigError`. |
| `encrypt(plaintext: str) -> str` | | Cifra con la clave ACTIVA con AES-256-GCM; nonce de 96 bits por llamada (`os.urandom(12)`); AAD = `enc:v1:<kid>`. Devuelve el token versionado. |
| `decrypt(token: str) -> str` | | Parsea el token, selecciona la clave por `<kid>`, verifica AAD+tag; devuelve el plaintext. Lanza `DecryptionError` ante malformato, kid desconocido/ausente o tag inválido. |
| `is_encrypted(value: str) -> bool` | | True sii `value` empieza por `enc:v1:`. |
| `CryptoConfigError` | excepción | Clave de cifrado ausente/inválida (fail-closed en carga/arranque). |
| `DecryptionError` | excepción | Integridad fallida o kid no disponible (fail-closed en operación). |

### Formato de token (design.md §1.2)

```
enc:v1:<kid>:<base64url(nonce)>:<base64url(ciphertext||tag)>
```

Ejemplo real con un **valor ficticio** (plaintext `"0001112223334445"`, clave de PRUEBA `test`):

```
enc:v1:test:AORma6HGW17zdHl2:gLG8jK3uNOpV9nhgSLefNyazHtQlp2jmjEcLuhZFqbo=
```

> Nota: cada cifrado usa un nonce nuevo, así que el valor exacto cambia en cada ejecución;
> el ejemplo ilustra la FORMA (5 segmentos `enc` / `v1` / `<kid>` / `<nonce>` / `<ct||tag>`).

### Decisiones de diseño honradas

- **AES-256-GCM** vía `cryptography.hazmat.primitives.ciphers.aead.AESGCM` (sin criptografía
  propia, R18.2).
- **Nonce** aleatorio de 96 bits por operación → dos cifrados del mismo texto dan tokens
  distintos.
- **AAD = `enc:v1:<kid>`**: manipular el `kid` del token invalida el tag (R2.4/R2.5).
- **base64url** (sin padding) para nonce y ciphertext.
- **Sin fallback a texto plano** (R2.3); fail-closed ante claves/integridad (R2.5).
- **Higiene de secretos** (R2.6): errores sin material de clave, nonce, ciphertext ni plaintext.
