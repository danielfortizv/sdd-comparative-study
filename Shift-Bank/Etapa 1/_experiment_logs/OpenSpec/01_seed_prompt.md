# Shift Bank - Stage 1 Experimental Seed

## Seed Version
1.0

## Prompt

Develop Stage 1 of a web application called Shift Bank.

Shift Bank is a basic banking application for an already authenticated mock user.

For this stage, the application must provide the following functionality:

1. Display the user's bank accounts and the current balance of each account.
2. Allow the user to transfer money between their own accounts.
3. Display the transaction history or movements associated with each account.
4. Include a mock multi-factor authentication (MFA) verification for sensitive transfer operations.

User registration, login, password recovery, external bank transfers, payments, credit cards, and other banking products are outside the scope of this stage.

The backend must be implemented in Python and the frontend must use React with TypeScript.

Follow the specification-driven development workflow provided by the development tool. Requirements, relevant edge cases, technical decisions, implementation tasks, code, and tests should be derived through that workflow rather than bypassing the specification process.
