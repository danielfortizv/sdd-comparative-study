- (decision) Adopt crisp institutional fintech aesthetic: Deep Trust Navy (#0A2540) primary, Action Cyan (#00D4B2) accent, slate neutrals
- (decision) Monetary typography standard: Inter with font-variant-numeric: tabular-nums for zero jitter in balance and ledger numbers
- (decision) Layout topography: Single unified desktop dashboard with 3-card account portfolio header and 2-column workspace (Transfer Panel + Movement Ledger)
- (decision) Account Card interaction: Selecting a card updates active ledger pane and pre-fills source account in transfer form
- (decision) Transfer form validation: Destination selector disables current source account; client-side balance validation prevents overdraft before submit
- (decision) Submit lock: Instant button disabled state and spinner prevents accidental duplicate submission
- (decision) MFA Verification Dialog: Focus-trapped modal displaying transfer preview, 300s countdown timer, 6-digit OTP input, and remaining attempts indicator
- (decision) MFA Error States: Distinct visual handling for invalid OTP (shake + attempts left), expired challenge (410 banner), and exhausted attempts (403 locked notice)
- (decision) MFA Cancellation: Modal close (Esc or Cancel button) aborts transfer cleanly with no fund deductions and returns to form
- (decision) Movement Ledger: Chronological descending rows with signed amount formatting (+$ green, -$ neutral) and post-transaction running balance
- (decision) Zero-Movement Empty State: Clean illustration and message on Emergency Reserve demonstrating FR-14 out of the box
- (decision) Accessibility: WCAG 2.1 AA compliance, visible focus rings, aria-live regions for toasts and balance updates
- (event) UX spines finalized and validated against UX rubric
