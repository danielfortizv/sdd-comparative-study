- (direction) Adopt Hexagonal architecture (Ports & Adapters) for FastAPI backend and Clean Component-Store for React frontend
- (decision) AD-1: Integer minor units (cents) enforced for all storage and computation; exact 2-decimal string serialization in API to eliminate float drift
- (decision) AD-2: Internal transfer atomicity via isolated SQLite transaction; balance conservation invariant strictly verified
- (decision) AD-3: Explicit separation between domain transfer state (PENDING_MFA, COMPLETED, CANCELLED, FAILED) and API initiation response status (MFA_REQUIRED, COMPLETED)
- (decision) AD-4: Single mock customer boundary: Alex Morgan (cust_mock_001) enforced via X-Customer-Id header and backend context dependency
- (decision) AD-5: Concurrency and duplicate submission protection via client UI lock and server-side 60s Idempotency-Key cache
- (decision) AD-6: MFA Challenge lifecycle managed with 300s TTL, 3 failed attempt ceiling, deterministic mock code 123456, and side-effect-free cancellation
- (decision) AD-7: Dual-entry immutable movement ledger: transfers generate linked DEBIT/CREDIT records with monotonic sequence tie-breaking
- (decision) AD-8: Pre-seeded portfolio: Checking (7 mvts, ), Savings (3 mvts, .75), Reserve (0 mvts, ) for out-of-the-box FR-14 verification
- (decision) AD-9: Frontend state management: optimistic balance updates banned; view transitions execute only upon verified API resolution
- (decision) AD-10: Standardized error envelope { error: { code, message, details } } mapped to semantic HTTP status codes (400, 403, 410, 422)
- (event) Architecture spine finalized and validated
