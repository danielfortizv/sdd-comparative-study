# E-Commerce Frontend (Stage 1)

This is the React + TypeScript single-page client application for the Stage 1 E-Commerce application.

## Prerequisites
- Node.js (v18+)

## Setup & Installation
1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

The UI will be available at: `http://localhost:3000`

## Build
To build the application for production:
```bash
npm run build
```
The output will be generated inside the `dist/` directory.
