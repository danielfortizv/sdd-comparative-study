# Calculator Stage Execution Commands

Run these commands in PowerShell with the current directory set to the root of `sdd-comparative-study`. They use the shared Python environment at `\.venv\Scripts\python.exe` and the shared Node dependencies in the root `node_modules`; no per-implementation dependency installation is needed.

Start a backend and its frontend in separate terminals. Run one implementation at a time. The backend commands set the app and reload directories to the selected implementation while leaving the shell at the repository root.

## Etapa 1

| Tool | Backend command | Frontend command |
| --- | --- | --- |
| Bmad Method | `& ".\.venv\Scripts\python.exe" -m uvicorn --app-dir "Calculadora\Etapa 1\Bmad Method\backend" --reload-dir "Calculadora\Etapa 1\Bmad Method\backend" app.main:app --reload --port 8000` | `npm --prefix "Calculadora\Etapa 1\Bmad Method\frontend" run dev` |
| Kiro | `& ".\.venv\Scripts\python.exe" -m uvicorn --app-dir "Calculadora\Etapa 1\Kiro\backend" --reload-dir "Calculadora\Etapa 1\Kiro\backend" app.main:app --reload --port 8000` | `npm --prefix "Calculadora\Etapa 1\Kiro\frontend" run dev` |
| OpenSpec | `& ".\.venv\Scripts\python.exe" -m uvicorn --app-dir "Calculadora\Etapa 1\OpenSpec\backend" --reload-dir "Calculadora\Etapa 1\OpenSpec\backend" app.main:app --reload --port 8000` | `npm --prefix "Calculadora\Etapa 1\OpenSpec\frontend" run dev` |
| Spec Kit | `& ".\.venv\Scripts\python.exe" -m uvicorn --app-dir "Calculadora\Etapa 1\Spec Kit\backend" --reload-dir "Calculadora\Etapa 1\Spec Kit\backend" src.main:app --reload --port 8000` | `npm --prefix "Calculadora\Etapa 1\Spec Kit\frontend" run dev` |
| Tessl | `& ".\.venv\Scripts\python.exe" -m uvicorn --app-dir "Calculadora\Etapa 1\Tessl\backend" --reload-dir "Calculadora\Etapa 1\Tessl\backend" app.main:app --reload --port 8000` | `npm --prefix "Calculadora\Etapa 1\Tessl\frontend" run dev` |
