# Cases

This directory will contain the approved case definitions used by the comparative study. The greenfield and brownfield cases are placeholders pending final approval by the thesis team and academic supervision.

Each case should define the same information before it is used in an experiment:

- functional requirements;
- non-functional requirements;
- constraints;
- acceptance criteria;
- initial repository state;
- external tests;
- dataset and load assumptions, if required.

Do not run or report an experiment against a case that has not been approved and frozen.
