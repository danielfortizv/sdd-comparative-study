# Academic Documents

This directory contains PDF copies of the LaTeX documents produced as part of the research project.

| File | Description |
| --- | --- |
| `thesis.pdf` | Presents the in-depth exploration of Spec-Driven Development (SDD) and the different tools evaluated in this project. |
| `article.pdf` | Presents a complementary practical study conducted collaboratively to support the development of the thesis. |

The article documents practical research that informed and supported the broader investigation presented in the thesis. The two documents are related but serve distinct purposes.

## Supporting Research Documentation

- [`methodology.md`](methodology.md) describes the study design, case studies, four development stages, experimental conditions, and procedure used to compare the SDD tools.
- [`evaluation-criteria.md`](evaluation-criteria.md) defines the five evaluation dimensions and the quantitative measures and qualitative criteria applied to the implementations.
- [`reproducibility.md`](reproducibility.md) explains the study's standardization goals, the limits imposed by LLM nondeterminism and platform differences, the exploratory scope of the findings, and the shared change-control matrix documented in `tabla etapas.tex`.
